# JakhonHangle JP Unity — 한국어 텍스트 및 선별 이미지 패치

작혼 일본 서버 웹버전용 비공식 시험판입니다. 현재 버전은 **2.0.0-beta.7**이며, 2026-10-25에 확인한 **Unity 4.0.18 / PC WebGL DXT** 리소스를 대상으로 합니다.

[설치 / 다운로드](https://gist.githubusercontent.com/mabinewb/e919e5a07216e5ff546be8789b070755/raw/JakhonHangle_JP_Unity.user.js) · [GitHub 직접 다운로드](https://raw.githubusercontent.com/mabinewb/jakhonhangle-jp-unity/main/JakhonHangle_JP_Unity.user.js)

## beta.7 변경 사항

- **다른 크기의 다각형 UI 교체:** beta.6에 남아 있던 같은 크기 조건을 제거했습니다. 「段位戦」「友人戦」 등 다른 크기의 한국어 이미지도 교체하며, 원래 표시 크기에 맞게 정점을 조정하고 텍스처 샘플링 위치를 유지합니다.
- **브라우저 탭 제목 한글화:** 게임 탭 제목을 `작혼 — 일본 서버`로 표시합니다.

- **튜토리얼 페이지 지원:** 후리텐 설명을 포함한 `course0`~`course8` 9개 페이지와 복잡한 다각형 이미지를 지원합니다. 일본판의 잘림 모양을 사용하지 않고 한국어판의 텍스처·메시를 함께 연결합니다. 원래 표시 크기와 기준점은 유지합니다.
- **배포 안내 페이지 이동:** 큰 Gist 파일 때문에 안내문이 표시되지 않는 문제를 피하도록 [GitHub 저장소](https://github.com/mabinewb/jakhonhangle-jp-unity)에 안내 페이지를 마련했습니다. 기존 직접 설치·업데이트 주소는 유지합니다.

- **공지 불러오기 수정:** 로그인 전 공지·점검·업데이트 정보와 로그인 후 공지 요청/알림은 일본 서버의 일본어 원문을 사용합니다. 화면 텍스트를 한국어로 고른 설정이 공지 요청 언어까지 바꾸던 문제를 수정했습니다. 공지 본문을 자동 번역하는 기능은 아닙니다.
- **Yostar 로그인창 문구 번역:** 이메일 주소, 인증 코드, 전송, 로그인, 계정 만들기 등 알려진 HTML 문구와 입력칸 설명을 한국어로 표시합니다. 입력값, 링크 목적지, 로그인/계정 생성 동작과 약관 본문은 변경하지 않습니다. 이미지나 등록되지 않은 문구는 일본어로 남을 수 있습니다.
- **대응되는 한국어 이미지 선별 교체:** 같은 UI 묶음 경로·이미지 키가 있으면 크기·종횡비 차이와 관계없이 한국어 이미지를 원래 표시 크기에 맞춥니다. 크기 제한을 제거했으며 현재 UI 이미지 902개를 포함해 총 923개 이미지를 108개 묶음에서 교체합니다. 원래 버튼 크기·배치·클릭 영역은 유지합니다. 크게 축소하거나 종횡비를 바꾸는 경우 글자가 작아지거나 늘어나 보일 수 있습니다. 브라우저가 필요한 공식 글로벌 리소스를 내려받아 해당 영역만 교체합니다. JP/KR 번들의 SHA-256을 검증하며, 다운로드 또는 검증에 실패하면 원본 이미지를 유지합니다.
- 원본 및 beta.2 수정 번들과 구분되는 beta.7 캐시 이름을 사용합니다.

로그인 버튼은 한국어판 **335 × 79**를 일본판의 원래 크기 **335 × 78**에 맞춰 교체합니다. 등록 완료 버튼도 작은 투명 모서리 잘림만 있어 원래 배치를 유지하며 한국어 이미지로 교체합니다. 인계 코드 안내는 대응되는 한국어 이미지가 없어 일본어로 유지합니다. 이미지 묶음을 통째로 한국어판으로 바꾸지 않습니다. 복잡한 다각형 이미지도 기준점이 같고 한국어 원본이 있으면 한국어 텍스처와 다각형 정보를 함께 가져옵니다. 외부 스트림, 미지원 압축 형식 등 현재 코드로 처리할 수 없는 이미지는 원본을 유지합니다. 현재 UI 목록에서 크기 차이 때문에 제외되는 항목은 없습니다.

## 설치 및 업데이트

1. Tampermonkey를 설치합니다.
2. 위 설치 주소를 열고 설치 또는 업데이트합니다. 소스만 표시되면 Tampermonkey의 기존 시험판 편집 화면에 전체 내용을 붙여넣고 저장합니다.
3. 스크립트 첫 부분의 버전이 `2.0.0-beta.7`인지 확인합니다. 구형 `JakhonHangle_JP_SERVER`와 중복 설치된 Unity 시험판은 꺼둡니다.
4. 게임 탭을 완전히 닫았다가 [일본 서버](https://game.mahjongsoul.com/)에 다시 접속합니다.

설치 후 초기에는 패치 준비 상태가 표시되고, 모듈 교체 후 왼쪽 위에 beta.7 문구가 나타납니다. 이는 모듈 처리 상태이며 모든 화면의 정상 작동을 보증하는 표시는 아닙니다.

## 지원 범위와 되돌리기

한국어 텍스트를 선택하면서 일본 서버 접속과 일본 클라이언트 구분을 유지합니다. 모바일/ASTC는 지원하지 않습니다. 게임 업데이트로 리소스나 코드가 바뀌면 수정이 필요합니다.

이미지는 비동기 fetch 경로에서 교체하며, XHR 경로에서는 안전하게 원본을 유지합니다. 필요한 글로벌 이미지 묶음만 추가로 다운로드하며, 일부 텍스처는 해당 영역을 바꾸기 위해 RGBA 형식으로 재구성하므로 메모리 사용이 늘 수 있습니다. 디코딩 가능한 텍스처 범위는 최대 16메가픽셀로 넓혔습니다.

문제가 생기면 이 스크립트를 끄고 게임 탭을 완전히 닫았다가 다시 엽니다. 계정 정보나 사이트 전체 저장 공간을 삭제할 필요는 없습니다.

비공식 클라이언트 수정입니다. 탐지되지 않음, 계정 안전성, 전체 화면의 번역 및 정상 작동을 보장하지 않습니다.

## 검증 범위

- beta.2에서 사용자 보고로 로그인 버튼 표시 복구를 확인했습니다.
- 일본 서버의 공개 공지 API에서 `lang=jp`는 공지 15개, `lang=kr`는 0개를 반환하는 것을 확인했습니다.
- 실제 Lua 공지 요청·알림·업데이트 정보 함수로 일본어 서버 요청과 한국어 화면 설정의 분리를 시험했습니다.
- 로그인창 표시 문구가 동적으로 번역되면서 입력값·링크·외부 영역은 유지되는지 DOM 테스트했습니다.
- 선별한 이미지 묶음 108개를 재구성해 UnityPy로 다시 읽었습니다. 이미지 923개의 크기·배치와 관련 없는 객체가 유지되는지 확인했습니다. 전체 이미지 픽셀 비교는 BC3 디코딩의 반올림 차이 범위(최대 3/255) 내에서 통과했습니다. 크기 조정 시 정확히 두 픽셀 사이에 걸리는 최근접 샘플링 경계선은 비교 라이브러리의 반올림 차이로 검사에서 제외했습니다.
- fetch/XHR 처리, 이미지 다운로드 실패 시 원본 유지, 캐시 이름 분리와 JavaScript 구문 검사를 통과했습니다.
- 추가 텍스처가 공식 한국어 원본과 일치하는지 검증했습니다. 크기가 다른 다각형은 원래 표시 크기와 텍스처 샘플링 위치를 유지하는지 검증했습니다. 튜토리얼 9개 페이지가 모두 포함되는지 검사했습니다.
- **beta.7의 실제 게임 화면 전체는 아직 검증하지 못했습니다.**

## 출처 및 라이선스

기존 [JakhonHangle_JP_SERVER](https://openuserjs.org/scripts/Shijjanggu/JakhonHangle_JP_SERVER)를 계기로 현재 Unity 클라이언트용으로 별도로 작성한 시험판입니다. 원본 제작자의 공식 업데이트가 아니며 게임 개발사·운영사와 무관합니다. 예전 스크립트는 구형 Laya 리소스와 일부 공지를 교체하는 방식으로, 현재 Yostar 웹 로그인창 문구를 직접 번역하는 코드는 없습니다.

배포 스크립트 코드의 라이선스는 MIT입니다. 교체 위치·크기 등의 메타데이터를 포함하지만 게임 이미지·번역 원본 파일은 배포하지 않습니다. 필요한 원본은 실행 시 공식 CDN에서 가져옵니다. 게임 및 리소스의 권리는 각 권리자에게 있습니다.
