# JakhonHangle JP Unity — 일본 서버 한국어 패치

현재 버전: **2.0.0-beta.13**. 작혼 일본 서버 PC 웹버전용 비공식 시험판입니다.

[설치·업데이트](https://gist.githubusercontent.com/mabinewb/e919e5a07216e5ff546be8789b070755/raw/JakhonHangle_JP_Unity.user.js?version=2.0.0-beta.13) · [GitHub 직접 다운로드](https://raw.githubusercontent.com/mabinewb/jakhonhangle-jp-unity/main/JakhonHangle_JP_Unity.user.js)

## beta.13 변경 사항

- **beta.11·12의 깨진 화면 재수정:** 추가 객체를 목록 뒤에 붙이던 저장 방식을 고쳤습니다. 객체 목록과 데이터 영역을 signed PathID 오름차순으로 재구성하고 마지막 데이터 정렬도 기존 저장 방식과 맞춥니다.
- 전체 261개 후보 묶음의 객체 인덱스와 데이터 영역이 UnityPy 저장 결과와 바이트 단위로 일치하는지 검증했습니다. 이전의 ID 딕셔너리 읽기 검사만으로는 발견되지 않던 순서 문제를 검사에 추가했습니다. 실제 게임 화면 복구 확인은 업데이트 후 필요합니다.

- **beta.11 표시 오류 수정:** 새 텍스처 ID를 묶음마다 -1부터 반복하던 코드를 제거했습니다. JP 묶음·KR 묶음·원본 텍스처 ID로부터 64비트 ID를 생성하고 충돌을 검사합니다. 기존 Sprite가 참조하는 일본판 아틀라스 텍스처는 통째로 교체하지 않습니다.
- 실제 전체 대응 묶음에서 추가 ID의 전역 중복이 없는지, 원래 아틀라스가 보존되는지 검사했습니다. 실제 게임 화면 확인은 업데이트 후 필요합니다.

- **실행 시 최신 리소스 자동 연결:** 배포 시점의 이미지 묶음 이름·해시·재구성 레시피를 고정하지 않습니다. JP/KR 목록과 각 이미지의 타입 정보를 실제 파일에서 읽습니다.
- **경로 이동 대응:** 전체 한국어 경로가 없으면 같은 파일명·경로 끝부분으로 후보를 찾습니다. 하나로 확정할 수 있을 때만 연결합니다.
- **여러 묶음 연결:** 한 JP 묶음에 여러 KR 묶음이 대응하는 경우도 함께 읽습니다. 분할된 규칙 설명 이미지도 포함됩니다.
- **고정 용량 제한 제거 유지:** 64 MiB 및 16메가픽셀 상한을 두지 않습니다. 한국어 원본 읽기 과정의 불필요한 번들 재생성을 생략했습니다.
- Lua 파일의 현재 묶음도 리소스 목록에서 찾습니다. Lua의 일본 서버 구분·공지 요청 언어를 유지하면서 화면 텍스트를 한국어로 고릅니다.

현재 대응 관계와 남는 항목은 [리소스 대응 현황](RESOURCE_MAPPING.md) 및 [전체 경로 CSV](RESOURCE_MAPPING.csv)에 정리했습니다.

## 설치

1. Tampermonkey에서 위 설치·업데이트 주소를 엽니다. 소스만 보이면 기존 시험판 편집기에 전체 코드를 붙여넣고 저장합니다.
2. 버전이 `2.0.0-beta.13`인지 확인하고, 구형 `JakhonHangle_JP_SERVER`와 중복 시험판은 꺼둡니다.
3. 게임 탭을 완전히 닫고 [일본 서버](https://game.mahjongsoul.com/)를 다시 엽니다.

왼쪽 위에 `beta.13 · 최신 경로 자동 연결`이 표시되면 목록 처리가 끝난 상태입니다. 개별 화면의 모든 번역 완료를 뜻하지는 않습니다.

## 지원 범위

2026-10-25의 게임 Unity 4.0.18 / PC WebGL DXT 및 serialized-file v22 타입 트리에서 검증했습니다. 같은 구조를 유지하는 업데이트는 새 목록을 읽어 대응합니다. 이미지 파일명까지 완전히 바뀌어 식별할 수 없거나, 엔진·타입 구조·Lua 코드 내용이 달라진 경우 추가 수정이 필요할 수 있습니다. 모바일 ASTC는 지원하지 않습니다.

같은 키의 한국어 텍스처와 메시를 연결하며 UI 크기가 다르면 일본판의 원래 표시 크기에 맞춥니다. 직접 사용하는 Texture2D도 대응 이름으로 연결합니다. 한국어 원본이 없거나 검증할 수 없는 항목은 원본을 유지합니다. 이미지 교체는 비동기 fetch에서 지원하며 XHR 이미지 요청은 원본을 유지합니다.

Yostar 로그인창의 알려진 HTML 문구·입력칸 설명과 탭 제목 `작혼`을 한글화합니다. 입력값·링크 목적지는 변경하지 않습니다. 공지 본문은 일본 서버 원문입니다.

문제가 생기면 스크립트를 끄고 게임 탭을 닫았다가 다시 엽니다. 계정 정보나 사이트 전체 저장 공간을 삭제할 필요는 없습니다.

## 검증

- 최신 JP/KR 목록 직접 해석 및 모든 대응 묶음 재구성.
- UnityPy로 한국어 텍스처 바이트·원래 Sprite 크기·정점·UV 변환·관련 없는 객체 보존 확인.
- JP/KR 묶음 이름이 모두 바뀌고 JP 이미지 폴더가 이동한 가상 업데이트 테스트.
- 이동 경로 후보가 중복되거나 KR 목록 다운로드에 실패하면 원본 유지.
- 한국어 로그인 문구·브라우저 제목, 일본 서버 Lua 공지·업데이트 요청 유지 테스트.
- 실제 게임 전체 화면은 아직 별도 확인이 필요합니다.

## 출처

[기존 JakhonHangle_JP_SERVER](https://openuserjs.org/scripts/Shijjanggu/JakhonHangle_JP_SERVER)를 계기로 현재 Unity 클라이언트용으로 작성한 별도 시험판입니다. 원 제작자의 공식 업데이트가 아니며 게임 개발사·운영사와 무관합니다. 비공식 클라이언트 수정으로 탐지 여부·계정 안전성을 보장하지 않습니다.

스크립트 코드는 MIT입니다. Unity serialized-file 형식과 공통 문자열 확인에는 [UnityPy](https://github.com/K0lb3/UnityPy)를 참고했습니다. 게임 이미지·번역 원본은 배포하지 않고 실행 시 공식 CDN에서 가져옵니다. 게임 리소스 권리는 각 권리자에게 있습니다.
